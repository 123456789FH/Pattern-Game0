مغامرات الأنماط العددية — النسخة الملونة
=========================================

طريقة التشغيل:
١) فك ضغط الحزمة.
٢) افتح index.html للتجربة على الكمبيوتر.
٣) للرفع على GitHub Pages: ارفع جميع الملفات والمجلد assets كما هي إلى المستودع.
٤) بعد النشر عبر HTTPS يعمل التطبيق على الجوال والآيباد والكمبيوتر، ويدعم PWA والعمل دون اتصال بعد أول زيارة.

محتوى اللعبة:
- ١٢ مرحلة متدرجة.
- المراحل تتناوب بين الزيادة والنقصان.
- طالب في مرحلة وطالبة في المرحلة التالية.
- أرقام عربية ٠١٢٣٤٥٦٧٨٩.
- نقاط، عملات، نجوم، ثلاث محاولات.
- نجوم متطايرة عند الإجابة الصحيحة والفوز.
- تصميم متجاوب للجوال والآيباد والكمبيوتر.
- شعار ملتقى التعليم التفاعلي والتذييل المعتاد.
